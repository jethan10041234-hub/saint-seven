# SAINT SEVEN v0.6 — 오리지널 사운드

이 프로젝트의 음악과 효과음은 `js/audio-score.js`의 독자적인 음표 배열, 발진기, 잡음 필터와 잔향 조합으로 제작했습니다. 외부 음악·성가 녹음·샘플·기존 곡의 선율을 사용하지 않았습니다. 게임 및 시연에서 사용하고 수정할 수 있으며 별도의 외부 음원 라이선스나 표시 의무가 없습니다.

실제 배포 음원은 `assets/audio/*.wav`에 있습니다. 모두 16,000 Hz, 모노, PCM 16비트입니다. 파일을 읽지 못하는 환경에서는 같은 합성 소스로 동일한 사운드를 생성할 수 있습니다. `SAINT_AUDIO_SCORE.manifest`와 `assetPaths`는 단일 HTML 제작 시 포함할 정확한 파일 목록을 제공합니다. runtime의 `SAINT_EMBEDDED[path]`에는 해당 WAV의 data URL을 넣을 수 있습니다.

| 용도 | 파일 ID | 길이 | 구성 |
|---|---|---:|---|
| 마을·야외 | `bgm_outdoor` | 24초 반복 | 절제된 플루트, 류트, 현악과 낮은 드론 |
| 성당·실내 | `bgm_church` | 24초 반복 | 느린 오르간, 모음 형태의 합성 합창, 긴 잔향 |
| 의식 | `bgm_ritual` | 24초 반복 | 낮은 드론, 불협화 현악, 느린 반복 맥박 |
| 일반 엔딩 | `bgm_ending_normal` | 24초 반복 | 종결되지 않는 부드러운 류트와 합창 |
| 배드 엔딩 | `bgm_ending_bad` | 24초 반복 | 불안한 저음, 드문 종, 구절 사이의 여백 |
| 진 엔딩 | `bgm_ending_true` | 24초 반복 | 차분한 플루트, 합창, 정리되는 화음 |
| 야외 환경음 | `ambience_outdoor` | 32초 반복 | 세기가 변하는 바람과 이에 맞춘 잎사귀 마찰 |
| 실내 환경음 | `ambience_interior` | 32초 반복 | 낮은 공기 흐름과 멀리서 들리는 바람 |
| 발걸음 | `step_dirt`, `step_grass`, `step_stone`, `step_church`, `step_wood` | 0.22–0.68초 | 흙, 풀, 돌, 성당 잔향, 나무를 각기 합성 |
| 상호작용 | `door_open`, `door_close`, `choice_focus`, `choice_confirm`, `dialogue_open`, `dialogue_tick`, `item`, `event_transition`, `ending` | 0.055–0.96초 | 문, UI, 대사, 발견, 전환과 엔딩 효과 |
| 드문 환경음 | `bird`, `bell` | 0.68초 / 4초 | 새와 먼 종소리; 반복 환경음에 강제로 삽입하지 않음 |
| 의식 타격 | `ritual_strike` | 3.6초 | 둔탁한 충격과 낮은 금속성 잔향 |

음악 구절의 릴리스와 잔향을 반복 시작점까지 감아 배치하고, 드론을 반복 길이에 맞는 정수 주기로 합성했습니다. 환경음 필터에는 한 주기의 준비 계산을 적용해 반복 경계의 불연속을 줄였습니다. 출력 진폭은 최대 0.6으로 제한하여 채널 혼합을 위한 여유를 남깁니다. 채널 음량과 장면 전환, 발걸음 타이밍, 드문 새·종의 스케줄은 `js/audio.js`가 담당합니다.

재생성: 프로젝트 루트에서 `node assets/audio/build_audio.cjs`를 실행합니다. 원본 소스의 결정론적 난수 시드를 사용하므로 같은 소스에서 동일한 WAV가 생성됩니다. `docs/audio-manifest.json`에는 각 파일의 크기, SHA-256, RMS, peak와 반복 경계 측정치가 기록되어 있습니다.

## 재생 및 통합 계약

스크립트는 `js/audio-score.js` 다음에 `js/audio.js` 순서로 불러옵니다. `SAINT_AUDIO.create({onChange})`는 오디오 컨텍스트를 즉시 만들지 않습니다. 게임 시작 버튼 또는 입력 처리 안에서 `audio.start()`를 직접 호출하면 `AudioContext.resume()`이 비동기 작업보다 먼저 실행됩니다. 장소는 `setScene({map,phase,ending})`으로 설정합니다. 같은 음악을 공유하는 장소에서는 재생 위치를 유지하며 다른 음악·환경음으로 이동할 때 약 1.4–1.6초에 걸쳐 교차 전환합니다. 타이틀 상태에는 음악이 없습니다.

WAV는 일반 웹 환경에서 로컬 프로젝트 파일로 읽습니다. 단일 HTML은 `SAINT_EMBEDDED['assets/audio/파일명.wav']='data:audio/wav;base64,...'`를 먼저 정의하면 됩니다. `file://`, 파일 누락, 네트워크/디코딩 실패 때에는 외부 요청 없이 같은 음원을 합성합니다. 브라우저 오디오 API 자체가 없거나 설정 저장이 차단되어도 게임을 중단시키지 않습니다.

| API | 용도 |
|---|---|
| `setEnabled(bool)`, `toggle()` | 전체 오디오 켜기/끄기; 개별 채널 설정은 유지 |
| `setChannelEnabled('bgm'\|'ambience'\|'sfx', bool)` | 채널 독립 켜기/끄기 |
| `setVolume('master'\|'bgm'\|'ambience'\|'sfx', 0..1)` | 전체 또는 개별 채널 음량 |
| `setDialogue(bool)`, `duck(milliseconds)` | 대사 중 음악·환경음 감소, 사건 효과음에 잠깐 공간 확보 |
| `sfx(id,{volume,pitch})` | 위 목록의 효과음; 동시 재생 개수와 UI 반복 간격 제한 |
| `dialogueTick(text)` | 구두점 제외, 최대 75ms당 한 번의 작은 대사 소리 |
| `footsteps(distanceDelta,map,surface,active)` | 충돌 해결 후 실제 이동거리로 48px마다 양발 교대 |
| `stopFootsteps()` | 즉시 발소리 잔향과 대기 중인 재생 취소; 보행 위상 유지 |
| `resetFootsteps()` | 문 이동·순간이동·다시 시작 때 거리와 발 위상 초기화 |
| `door(cue)` | 실제 문은 여는 소리와 340ms 뒤 작은 닫힘 소리, 길·계단은 작은 전환 소리 |
| `ritualTick(seconds,kind)` | 의식 진행에 맞춘 긴장 변화와 타격 직전의 음악 정적 |
| `snapshot()`, `dispose()` | 상태·재생/효과음 기록 확인, 모든 소스와 타이머 정리 |

`footsteps`의 지면은 `dirt`, `grass`, `stone`, `church`, `wood`, `default`입니다. `default`는 낮은 음량의 중립적인 흙 발소리를 쓰며 없는 지면 데이터를 추측하지 않습니다. 방향 전환 자체에는 소리가 없고, 이동거리 0 또는 정지 시 소리가 멈춥니다. 128px 이상의 순간적인 위치 변화와 다른 맵의 이동값은 걷기로 처리하지 않습니다. 보행 주기 96px의 두 발 착지 지점과 간격이 일치합니다.

음량 기본값은 master 0.75, BGM 0.42, 환경음 0.30, 효과음 0.52입니다. 대사 중 BGM은 기본값의 55%, 환경음은 72%로 내려갑니다. 의식은 낮은 드론에서 시작해 3.45초 동안 상부의 불협화 현악이 점차 드러나고, 일반·배드 의식 3.45–4.4초 / 진 엔딩 의식 3.65–4.55초에는 음악을 줄여 결정적 동작을 강조합니다. 이 시간은 현재 시네마틱 타격·중단 연출 기준이며 연출 시간 변경 시 함께 조정합니다.

새는 야외에서 대략 23–45초 간격, 먼 종은 성당과 성당 앞에서 대략 47–75초 간격으로 작게 들립니다. 환경음 채널을 끄면 이 소리도 함께 꺼집니다. 숨겨진 탭은 컨텍스트를 일시 정지하고 돌아올 때 이어 재생하여 밀린 환경음이 한꺼번에 나오지 않습니다.

검증 명령은 `node tests/audio.test.cjs`입니다. 실제 WAV, 내장 data URL, 파일 누락 및 `file://` 합성 경로, 사용자 입력 잠금 해제, 중복 소스 방지, 보행 동기와 중단, 채널 음량, 의식 정적, 3개 엔딩, 탭 숨김/복귀 및 API 부재 예외를 검사합니다. 자동 검증은 실제 브라우저 청취와 시연 검사를 대신하지 않습니다.

문 닫힘 소리는 실제 `door`, `churchDoor`, `gate` 출입만 대상으로 340ms 뒤 작게 재생됩니다. 새 출입이나 다른 맵 도착, 타이틀 복귀, 전체/효과음 음소거, 탭 숨김과 dispose 시 예약을 취소합니다. 이미 시작한 문소리와 아직 파일을 읽는 문소리도 출입 세대 번호로 정리하므로 빠르게 오갈 때 이전 문의 닫힘이 뒤늦게 재생되지 않습니다.
