# SAINT SEVEN v0.6

## 실행

시연에는 **`SAINT_SEVEN_v06_play.html` 단일 실행본**을 권장합니다. 브라우저에서 직접 열면 됩니다. 이미지·폰트·음원이 포함되어 있어 인터넷 연결이나 Node.js·npm 설치가 필요하지 않습니다.

ZIP 소스는 전체를 압축 해제하고 `index.html`을 여세요. 개발할 때는 VS Code의 Live Server 등 로컬 웹 서버로 열 수 있습니다. 파일을 직접 여는 환경에서도 오디오 파일을 읽을 수 없으면 내장 합성 소스로 재생합니다. 게임은 외부 서버나 CDN을 사용하지 않습니다.

타이틀의 시작 버튼을 눌러야 소리가 활성화됩니다. 진행 상황은 새로고침하거나 처음부터 다시 시작하면 초기화되며, 소리 설정은 브라우저가 허용하는 경우에만 유지됩니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동. 마지막 방향 유지, 동시에 누른 방향은 나중 입력 우선 |
| 문·출입구를 향해 걷기 | 닿으면 자동 이동. 기존 E 이동도 유지 |
| E / Enter | 가까운 인물과 대화, 조사, 다음 대사 |
| 클릭 / Tab → Enter | 선택지와 버튼 선택 |
| Q | 살펴본 자료와 판단에 반영한 내용을 탐색 기록에서 확인 |
| Esc | 메뉴 열기 / 열린 창 닫기. 자료 확인과 약속의 마지막 단계에서는 판단 보류 |
| AUDIO ON/OFF | 전체 소리 켜기·끄기 |
| 메뉴 → 소리 설정 | 전체 음량과 배경음악·환경음·효과음의 ON/OFF 및 음량 조절 |
| Enter / 장면 건너뛰기 | 의식 집행 컷신 건너뛰기. E는 컷신을 넘기지 않음 |
| B | 제작용 충돌 영역 표시 |

대화·기록·메뉴 중에는 이동이 멈춥니다. 엔딩에서는 다음·이전으로 문단을 읽거나 전체 문구를 볼 수 있습니다. 질문을 읽은 뒤 선택을 돌아보거나, 건너뛰고 타이틀로 돌아갈 수 있습니다.

## v0.6 추가 내용

- **오리지널 WAV 25개:** 장소별 배경음악 6개, 반복 환경음 2개, 지면별 발걸음 5개와 문·선택·대사·발견·전환·종·의식 등의 효과음을 포함했습니다. 외부 음악이나 녹음 샘플은 사용하지 않았습니다.
- **장면별 사운드:** 마을·야외, 성당·실내, 의식, 세 엔딩의 음악이 부드럽게 전환됩니다. 같은 음악을 사용하는 일반 맵 이동에서는 재생 위치를 유지합니다. 대화 중 음악과 환경음이 낮아지며, 타격 직전에는 정적을 둡니다.
- **걷기와 연결된 발소리:** 충돌 해결 후 실제 이동거리에 맞춰 양발이 교대합니다. 흙·풀·돌·성당·나무 지면을 구분하고, 정지·대화·문 이동에서는 발소리를 멈추거나 초기화합니다. 지면을 확정하지 못한 곳에는 기본 소리를 사용합니다.
- **세 엔딩 일러스트:** 일반·배드·진 엔딩에 각각 전용 그림을 표시하고 네 개의 짧은 캡션을 순차적으로 보여줍니다. 기존 인물과 각 엔딩의 희생·생존 결과를 유지합니다.
- **열람과 판단 반영 분리:** 문서를 읽는 것만으로 상태가 변하지 않습니다. 확인 버튼으로 판단에 반영하거나 Esc로 보류할 수 있습니다. 탐색 기록에서 열람한 자료를 다시 볼 수 있습니다.
- **주장과 관찰 구분:** 단서의 출처, 관찰한 내용과 확인하지 못한 범위를 표시합니다. 주민들의 믿음·두려움·의문을 기존 주민 슬롯에 나누어 배치했습니다.
- **선택의 의미 표시:** 노인과의 재대화 마지막 버튼은 대신 나서겠다는 약속임을 명시합니다. 원래의 마지막 진행 버튼 한 개를 유지하며 Esc로 보류할 수 있습니다. 일반 엔딩에서도 그 약속을 했던 경우에는 대사와 캡션에 반영합니다.
- **엔딩 질문:** 각 엔딩에 질문 두 개를 남깁니다. 답변을 입력하거나 고르는 기능, 답변 저장·전송·평가는 없습니다. 열람·선택 내역은 현재 실행 중인 게임 상태로만 사용합니다.

사운드 구성과 재생성 방법은 `docs/AUDIO_MANIFEST.md`, 문장별 원문 비교와 학습 목표·선택 결과의 연결은 `docs/NARRATIVE_REVIEW_KO.md`에 정리했습니다.

## v0.5 필수 기능 유지

- 실제 브라우저 표시 영역에 맞춘 전체 화면 배치, 게임 캔버스 3:2 비율과 픽셀 선명도, 가로·세로 스크롤 없는 배치를 유지합니다. 화면비 차이는 여백과 UI 배치로 처리합니다.
- 확대된 한글 픽셀 폰트, 긴 기록의 페이지 처리, 짙은 올리브·아이보리·금색 UI를 유지합니다.
- 기존 여섯 맵과 열두 출입구를 사용합니다. 자동 입장·퇴장, 스토리상 접근 제한, 도착 좌표, 연속 왕복 방지를 유지합니다.
- 호르마셋과 세븐의 네 방향 원본 스프라이트에서 발·발목을 교대로 움직이고, 양손은 반대 주기로 흔들며 몸은 0–2px 들썩입니다. 정지하면 원래 대기 자세로 돌아옵니다.
- 앉은 세븐은 실제 인물 경계와 공통 픽셀 배율을 기준으로 표시합니다. 앉은 자세를 서 있는 인물 높이까지 늘리지 않습니다.
- 주민 여섯 종류의 외형을 새 게임마다 중복 없이 무작위 배치합니다. 같은 주민은 성당과 광장에서 같은 외형을 유지합니다.
- 일반 엔딩의 세븐 처형, 배드 엔딩의 호르마셋 처형, 진 엔딩의 의식 중단 컷신을 유지합니다. 다른 탭으로 이동하면 연출 시간이 멈춥니다.
- 기존 주요 인물 전신 원본과 어깨 초상화, 반투명 전신 연출, 대화와 선택지, 조사와 상호작용을 유지합니다.

걷기 비교 이미지는 `docs/walking_preview.gif`에 있습니다. v0.5의 단일 48초 합성 BGM은 v0.6에서 장면별 음악과 채널 시스템으로 확장했습니다.

## 단서와 엔딩 규칙

양피지를 먼저 확보한 뒤 다른 조사와 판단을 진행합니다. 확인한 단서를 다시 읽어도 수치는 중복해서 올라가지 않습니다.

| 단서·대화 | 선행 조건 / 위치 | 판단에 반영할 때의 기존 효과 |
| --- | --- | --- |
| 찢어진 양피지 | 성당 지하실 | 수치 변화 없음, 다른 단서의 선행 도구 |
| 세븐의 일기장 | 양피지 확보 후 세븐의 집 침실 | 의심 +1 |
| 풀과 복원 도구 | 양피지 확보 후 정원 벤치 앞 | 양피지 복원, 의심 +1 |
| 성경책 | 양피지 확보 후 성당 제단 앞 | 신뢰 +1 |
| 바뀐 성경책 커버 | 성경책을 열람하거나 판단에 반영한 뒤 같은 곳 재조사 | 의심 +1 |
| 주민의 희생 독촉 | 양피지 확보 후 주민 재대화 마지막에 약속 | 신뢰 +1 |
| 엘리의 근거 설명 | 양피지 확보 후 설명을 믿는 선택 | 신뢰 +1 |
| 엘리의 의식 설명 | 앞선 엘리 설명을 받아들인 뒤 필요성에 동의 | 신뢰 +1 |

커버의 선행 조건만 성경책의 **열람 또는 판단 반영**으로 넓혔습니다. 책의 예언을 믿지 않아도 책의 물리적인 차이를 확인할 수 있습니다. 단서 ID, 각 효과, 중복 방지와 나머지 선행 조건은 유지합니다.

조건이 겹치면 **의심 3 이상 → 진 엔딩, 그 외 신뢰 4 이상 → 배드 엔딩, 그 외 신뢰 3 이상 → 일반 엔딩** 순서입니다. 조건 미달이면 조사를 계속합니다. 행동 횟수 제한이나 자동 의식 호출은 없으며, 엘리에게 의식에 관한 판단을 전해 제단으로 이동합니다.

### 세 엔딩 시연 동선 — 스포일러

아래에서 “반영”은 자료 팝업의 확인 버튼을 누르는 행동입니다.

- 진 엔딩: 양피지 확보 → 일기 반영 → 정원에서 복원 반영 → 성경책 열람 → 같은 곳 재조사에서 커버 반영 → 엘리에게 의식 요청 → 제단에서 모순 지적. 성경책 자체의 신뢰는 올리지 않아도 됩니다.
- 일반 엔딩: 양피지 확보 → 성경책 반영 → 엘리의 두 추가 설명 수락 → 의식 요청. 의심은 3 미만으로 유지합니다.
- 배드 엔딩: 일반 동선에 주민 재대화의 대리 희생 약속을 더해 신뢰 4 → 의식 요청. 의심은 3 미만이어야 합니다.

## 원본과 문구 수정의 경계

`js/story.js`와 `js/data.js`의 기존 자료를 보관하고, `js/narrative.js`가 장면별 문장과 단서 본문만 선별적으로 덮어씁니다. 장면 키·페이지 수·화자·주민 슬롯을 유지하며, 실제 게임은 이 문구 계층을 적용해 표시합니다. 맵·충돌·출입구·캐릭터 정의와 그림 원본은 문구 수정 대상이 아닙니다.

일반 엔딩의 세븐 희생, 배드 엔딩의 호르마셋 희생, 진 엔딩의 의식 저지를 바꾸지 않았습니다. 마을 위험의 원인이나 새로운 저주 규칙, 대리 희생을 허용하는 혈통·자발성 예외를 새로 만들지 않았습니다. 엘리의 주장, 기록의 내용, 직접 관찰한 사실을 구분하고, 소스에 없는 의식의 효력이나 동기의 전부를 확정하지 않습니다.

기존 PDF는 화면 배치 참고 자료로 사용했습니다. 이전의 ‘세븐의 신뢰’나 핵심 증거 두 개 조건 대신 현재 구현의 엘리 의심·신뢰와 엔딩 기준을 유지합니다. 두 엘리 추가 대화, 단서 본문, 주민 재대화, 의식 연결 문장은 기존 버전의 구현 보완 문안이며 v0.6의 선별 수정 내역은 시나리오 검토 문서에서 비교할 수 있습니다.

## 검증

최종 실행 환경, 통과 결과와 남은 제한은 **`TEST_REPORT_KO.md`의 최종 결과**를 참조해 주세요.

- `node tests/rules.test.cjs`: 상태와 엔딩 경계값.
- `node tests/portals.test.cjs`: 출입구 연결과 이동 판정.
- `node tests/audio.test.cjs`: 음원·채널·반복·발걸음 동기·예외 처리.
- `tests/browser.html`, `tests/feedback.html`: 기존 이야기·엔딩·반응형·걷기·출입구 검사.
- `tests/compact.html`, `tests/v06.html`: 작은 화면 및 v0.6 자료·소리·엔딩의 브라우저 검사.

브라우저 검증 페이지는 로컬 웹 서버에서 엽니다. 바깥 프레임은 결과표를 보여주며, 검사 중 게임 내부 viewport는 지정한 해상도를 사용합니다. `?__test=1`에서만 검증 API가 노출됩니다.

음악과 효과음은 프로젝트의 독자적인 음표·발진기·잡음·잔향 조합으로 제작했습니다. 외부 곡이나 성가 녹음, 샘플을 사용하지 않았습니다. 소스와 함께 게임·시연에서 사용하고 수정할 수 있습니다.

## 수정한 소스로 단일 실행본 다시 만들기

게임 실행에는 설치가 필요하지 않습니다. 소스를 수정한 뒤 단일 HTML을 다시 만들 때만 Python 3에서 `python tools/build_standalone.py`를 실행합니다. 프로젝트 폴더 바로 위에 `SAINT_SEVEN_v06_play.html`이 생깁니다. `--output 원하는/파일.html`로 출력 위치를 지정할 수 있습니다. 그림과 음원, 글꼴까지 포함하며 별도 Python 패키지는 필요하지 않습니다.
